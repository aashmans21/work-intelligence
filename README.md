# LinkedIn Work Intelligence - Demo Application

LinkedIn AI Work Intelligence platform demo for CoStar Group case competition.

## Quick Start

Simply open `index.html` in any modern web browser. No build process required!

## Features

- 11 interactive screens showcasing workforce intelligence
- 3-tier plan gating system (Insight, Activate, Transform)
- Interactive charts powered by Chart.js and D3.js
- Smooth animations and transitions
- LinkedIn design system integration

## Demo Presentation Flow

1. **Overview** - Workforce intelligence KPIs and metrics
2. **Skill Heatmaps** - Operational friction analysis
3. **Project Marketplace** - Skills-based project staffing
4. **AI Matching** - Intelligent candidate matching
5. **Team Assembly** - Optimal team composition
6. **Plans & Features** - Pricing tiers

Perfect for a 2.5-minute live presentation!
